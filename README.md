# City Hero: Save Your City

A 3D civic-awareness educational game developed using Godot 4.

## Overview

City Hero is an interactive game project focused on civic responsibility and urban problem-solving.

Players explore a 3D city environment and encounter challenges involving:

- Traffic Safety
- Waste Management
- Pollution Control
- Emergency Response
- Cyber Safety
- Water Conservation

## Gameplay Systems

- Interactive civic challenges
- Reputation and scoring system
- Six-level progression concept
- Quiz-based activities
- In-game phone interface concept
- 3D urban environment

## Technology

- Godot Engine 4
- GDScript
- Godot 3D environment and physics systems
- Godot UI system

## Getting Started

1. Install Godot 4.
2. Clone this repository.
3. Open Godot.
4. Select Import.
5. Choose the folder containing `project.godot`.
6. Import and run the project.
